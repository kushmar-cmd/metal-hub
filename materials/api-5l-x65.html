ערכים טיפוסיים למצב המסירה שבכותרת

X65 היא דרגה בתקן API 5L לצנרת הולכה. המספר מציין את גבול הכניעה המינימלי: 65 ksi (448 MPa). בתקן הבינלאומי ISO 3183 היא נקראת L450. היא פלדת פחמן-מנגן עם מיקרו-סגסוג, בפחמן נמוך, כדי שתהיה חזקה ועדיין תתרתך היטב בשטח.

בתקן יש שתי רמות דרישות: PSL1 ו-PSL2. ב-PSL2 הדרישות מחמירות יותר, כולל גבול כניעה מרבי, בדיקות הלם והגבלת פחמן שווה-ערך. לשירות "חמוץ" (עם H2S) יש דרישות נוספות לפי NACE MR0175.

מצבי אספקה וטיפול תרמי

בפלדות מבנה, לחץ וצנרת, החומר נבחר לפי גבול כניעה מינימלי ועמידות להלם בטמפרטורה מסוימת, ולא לפי טיפול תרמי שהמשתמש מבצע. מצב האספקה מוגדר בתקן.
