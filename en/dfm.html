📐 DFM Principles — Basic Rules
The 10 Golden Rules of DFM
1. Simplify shapeEvery added feature = an added setup = cost. Ask: ← is it really needed?
2. Minimal toleranceDon't call out IT7 when IT11 is enough. Each grade = ×1.5–2 in cost
3. Minimal RaRa 3.2 = standard turning. Ra 0.8 = grinding. Ra 0.2 = lapping ← ×10 cost
4. Standard material1045/6061/304 = off the shelf. Inconel 718 = 6 weeks + ×8 price
5. Standard sizes⌀25 rod = shelf stock. ⌀27 rod = special order
6. Unified DatumDimension from one Datum — not a chain! ← ↓error accumulation
7. Tool accessIf the tool can't reach — it can't be machined! Consider L/D and angles
8. WorkholdingYou need a gripping surface! Round part ← chuck. Flat ← vise
9. Minimize setupsEvery setup = ±0.02–0.05mm error + time. Design for Done-In-One
10. Consider mass productionWhat works for 1 part isn't necessarily economical for 10,000
▸ Rule of thumb: 80% of manufacturing cost is determined at the design stage!
▸ A drawing change = $30. A production change = $3,000. A field change = $30,000

Common Drawing Mistakes
❌ Avoid!
❌ Tolerance on everythingOnly functional dimensions! Everything else = ISO 2768-m
❌ Ra 0.8 on everythingOnly fit and sealing surfaces! Everything else = Ra 3.2–6.3
❌ Sharp cornersAlways R ≥ 0.2mm — a tool can't make R0! Stress riser!
❌ Deep hole ≫ 5DGun drilling = ×5 cost. Design for L/D ≤ 4
❌ Wall too thinVibration + distortion. Minimum 2mm steel, 3mm Al
❌ Chained dimensionsError accumulation! Use a single Datum
❌ Excessive GD&TPosition ±0.01 on an M6 screw? The screw has 0.5mm of clearance!
❌ Exotic materialInconel when SS 316 is enough? ← check actual operating conditions

🔄 DFM — Turning
DFM Rules for Turning
L/DMaximum 4:1 unsupported. 10:1 with a steady rest. 20:1+ = problematic
Diameter stepsDesign large to small — avoid undercut pockets
UndercutAvoid! If necessary — use DIN 509 standard (E/F/G/H)
O-Ring groovesUse a standard tool — width ≥ 1.5mm
Thread runoutAllow a thread relief before the shoulder — 2× pitch minimum
CentersAdd a center drill A2.5/B4 — for holding between centers
ChamferC0.5–C1 on every edge! Prevents burrs + eases assembly
Minimum wallTube: t ≥ D/20 (steel) · t ≥ D/15 (Al)
❌ Don't
A long L/D=12 part with no support ← vibration, deviation, poor Ra
✅ Do
L/D ≤ 4, or add a steady rest. Long part ← between centers
❌ Don't
A sharp R0 internal corner between diameters ← a special grooving tool
✅ Do
R ≥ 0.4mm internal corner — standard VNMG tool

Undercuts — DIN 509
Type ENarrow groove — for ordinary shoulders
Type FGroove + grinding — for high precision
Type GWide groove — thread relief
Type HRadial groove — O-Ring grooves
When to avoidIf the shoulder isn't functional — a simple R is ×10 cheaper
Swiss-Type — DFM Rules
Maximum diameter≤ 32mm (most machines) · ≤ 38mm (large ones)
Maximum length≤ 300mm from the bar feeder
Guide BushOuter diameter h6 → a smooth surface! Chuck marks = a problem
Cross DrillingPossible with live tools — plan the center
Back WorkA sub-spindle for OP2 — design for the other side
▸ Swiss = perfect for small, complex parts
▸ If there are more than 5 different features — Swiss beats a standard lathe
⚙️ DFM — Milling
DFM Rules for Milling
Corner radiusR ≥ ½ tool diameter! An R3 corner ← a ⌀6 tool minimum
Pocket depthMaximum 4× tool diameter. A 20mm-deep pocket ← a ⌀5+ tool
Pocket wallThickness ≥ 2mm steel / 3mm Al — vibration!
Internal cornerNever R0! A round tool always leaves a radius. Add a dog bone / T-bone relief
Workholding surfaceLeave ≥ 15mm for a vise, or design tabs
5-axis vs 3-axis3-axis = a setup per side. 5-axis = one setup but ×2 machine cost
Number of setupsDesign for a maximum of 2 setups. Each setup = ±0.03mm error
Text / MarkingEngrave is better than emboss — less machining. Height ≥ 3mm
❌ Don't
A pocket with a sharp R0 corner ← impossible in milling!
✅ Do
R ≥ 3mm pocket corners. If R0 is needed — add a dog bone relief
❌ Don't
A 40mm-deep pocket with a ⌀6 tool ← L/D=6.7 ← vibration, breakage
✅ Do
A 40mm pocket ← a ⌀12 tool (L/D=3.3) or trochoidal step-down

3-Axis vs. 5-Axis — When?
3-axis is enoughA prismatic part, 1-2 sides, straight pockets
3+2 (Indexed)5 sides, but each side is flat — ← enough!
5-sim requiredImpellers, blisks, complex surfaces, undercuts
3-axis hourly rate$30–60/hr
5-axis hourly rate$70–150/hr
▸ If 3+2 is possible — don't pay for 5-sim!
▸ 5-sim = only needed when the tool must move at an angle simultaneously
🔩 DFM — Holes and Threads
Holes — DFM Rules
Standard diameter⌀3/4/5/6/8/10/12/16/20 — off-the-shelf drill!
L/D ≤ 4Standard drilling — ×1 cost
L/D 4–10Peck drilling required — ×2 cost
L/D > 10Gun drilling — ×5–10 cost!
Blind holeA conical bottom at 118°/135° — a flat bottom is impossible!
Straight entryThe drill must enter perpendicularly! An angled surface = drift
Straight exitA drill exiting ← a burr. Design a chamfer at exit or plan deburring
Hole spacing≥ 2× diameter — otherwise wall distortion
Distance from edge≥ 1.5× diameter — otherwise breakout
❌ Don't
A ⌀6 hole, 60mm deep (L/D=10) ← gun drill ← ×5 cost
✅ Do
A ⌀6 hole, 24mm deep (L/D=4) ← standard drill ← ×1

Threads — DFM Rules
Thread depth1.5D in steel, 2D in aluminum, 2.5D in plastic
Thread ReliefA 2× pitch groove ← ← ← ← mandatory for turning!
Blind holeDrilling depth = thread depth + 3× pitch
Standard sizesM3/M4/M5/M6/M8/M10/M12 — don't invent one!
Standard pitchUse Coarse! Fine only when truly needed (vibration)
HelicoilIn Al with a critical thread — plan for an STI insert up front
Thread MillLarge holes (>M16) ← thread milling is preferable
❌ Don't
M4 at 20mm depth in aluminum (5D!) ← the tap will break
✅ Do
M4 at 8mm depth (2D) in aluminum + a Helicoil if critical

💎 DFM — Grinding
When Is Grinding Really Needed?
IT5 and belowTurning/milling can't reach it ← grinding is mandatory
Ra ≤ 0.4μmTurning barely reaches 0.8 ← grinding
HRC > 45Hard turning is possible (CBN) but grinding = ↑Ra
Roundness ≤ 5μmCenterless grinding
Flatness ≤ 5μmSurface grinding
▸ If IT7 + Ra 0.8 is enough — finish turning is enough!
▸ Grinding = ×3–5 cost vs. turning
▸ Design stock for grinding: 0.1–0.3mm per side
▶ YouTube
DFM Rules for Grinding
StockLeave 0.1–0.3mm/side for grinding. Too much = time. Too little = not enough
UndercutsA grinding relief groove ← the wheel can't grind a shoulder!
CentersCenter holes are mandatory for grinding between centers!
KeywayA keyway interrupts OD grinding ← grind before keyway cutting
RunoutGrinding ← excellent runout. Design Datum A on the ground OD
HardnessHeat treat before grinding! HRC55-62 ← CBN wheel

📄 DFM — Sheet Metal and Bending
DFM Rules for Sheet Metal
Minimum bend RR ≥ t (sheet thickness). R < t = cracking!
Recommended RR = 1–2t — safe for most materials
Minimum flange length≥ 4t + R — otherwise the sheet slips from the die
K-Factor0.33 (air bend) / 0.42 (bottom) / 0.5 (coining)
Bend AllowanceBA = π/180 × α × (R + K×t) ← ← critical for the flat pattern!
Hole distance from bend≥ 2.5t + R — otherwise the hole distorts!
Grain directionBend ⊥ to the rolling direction — ↓cracking
Standard thickness0.5/0.8/1.0/1.2/1.5/2.0/2.5/3.0mm ← off the shelf!
❌ Don't
An R=0 bend in 2mm steel ← cracking on the outer side!
✅ Do
R ≥ 2mm (= 1t) for 2mm steel. Al ← R ≥ 1t works
❌ Don't
A ⌀5 hole 3mm from a bend in 2mm sheet ← the hole distorts
✅ Do
A ⌀5 hole at ≥ 7mm (2.5t+R) from the bend

🔥 DFM — Casting
DFM Rules for Casting
Uniform wall thickness↓thickness differences ← ↓shrinkage + porosity
Minimum thicknessSand: 5mm · Die Cast: 1–2mm · Investment: 1mm
Draft AngleSand: 1–3° · Die Cast: 0.5–2° · Investment: 0.5°
CornersR ≥ t/3 internal · R ≥ t external ← ↓stress concentration
UndercutsAvoid! If necessary ← side core / collapsible core
Parting LineDesign it flat! ← simplifies the mold
ToleranceSand: ±1mm · Die Cast: ±0.1–0.3mm · Investment: ±0.1mm
Machining Stock2–5mm per side on machined surfaces
▸ Rule #1: uniform thickness! A ×2 difference = shrinkage + hot spots
▸ Ribs: rib thickness = 0.6–0.8× wall thickness
▸ Bosses: OD boss ≤ 2× ID — otherwise sink marks

⚡ DFM — Welding
DFM Rules for Welding
Welder access↑space = ↑quality. Minimum 30° angle for the welder
Fillet vs. GrooveFillet Weld = simple. Groove Weld = ↑strength, ↑cost
Fillet sizea = 0.7× the thinner thickness — no more!
SymmetrySymmetric welding ← ↓distortion. Alternate sides if possible
Minimize weldsFewer seams = less distortion = less NDT = lower cost
Avoid crossingsIntersecting seams = stress concentration! Offset ≥ 50mm
Edge preparationV/U/J-Groove: standard AWS D1.1 Table 4.3
Back GougingFull penetration ← requires back gouging + welding from the other side
❌ Don't
A fillet weld a=10mm on 6mm steel ← over-weld ← distortion
✅ Do
A fillet weld a = 0.7×6 = 4mm ← ← enough + ↓distortion

Weld Distortion — Prevention
Pre-SetPre-bend in the opposite direction before welding ← straightens after
Weld sequenceFrom the center outward, alternating, symmetric
Back-StepWelding in the reverse direction ← ↓longitudinal distortion
FixturingJigs + clamps + tack welds — hold the shape
PreheatSteels >25mm / CE>0.45 / T<5°C ← preheat
PWHTStress relief 600–650°C/1h per 25mm — ASME VIII
Stress ReliefVibratory (VSR) — a cheap alternative to PWHT

🔧 DFA — Design for Assembly
DFA Principles
Reduce partsEvery part = purchasing + inventory + assembly + a possible defect. ↓parts = ↓cost
3 questions1) Moves relative to neighbors? 2) Different material? 3) Needs to be removable? If not — combine!
Assembly directionZ-axis only! Avoid flipping ← ↓time ← ↓errors
Self-LocatingParts that locate themselves — chamfer lead-in, snap-fit
Poka-YokeDeliberate asymmetry ← only one correct way to assemble!
StandardizationOne M5 screw everywhere — not M3+M4+M5+M6!
AccessA wrench/screwdriver needs space! ≥ 20mm around a screw
Snap-FitBetter than a screw! ← ← zero purchased parts, instant assembly
▸ Boothroyd-Dewhurst: ← a proven DFA method — calculates assembly time per part
▸ Rule of thumb: ↓50% parts = ↓30% cost ← ← ← immediate ROI
▸ A screw = 6 seconds. A snap-fit = 1.5 seconds. ← ×4 faster
▶ YouTube
Poka-Yoke — Mistake-Proofing
Locating pin2 pins — 1 round + 1 diamond ← unambiguous location
AsymmetryA key / slot / protrusion ← a single assembly direction
Color codingA red connector ← a red socket. Impossible to mix up
Different sizesConnector A = ⌀8, connector B = ⌀10. Cannot be swapped
D-Sub / USBA trapezoidal / asymmetric shape ← a single orientation
❌ Don't
A symmetric part ← the worker assembles it backwards 50% of the time
✅ Do
A tab/slot on one side ← correct assembly 100% of the time
