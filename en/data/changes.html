📋 Engineering Change Process — ECO/ECN
1. Change Request (ECR)
  · Submitter: engineering / manufacturing / customer
  · Change description + rationale + impacts
  · Part number + current Rev
2. Impact Analysis
  · Affected parts (Where-Used)
  · Existing inventory — what to do with it?
  · Cost + timeline
3. Approval (ECO Board / CCB)
  · Engineering + manufacturing + purchasing + stores
  · Effectivity date
4. Implementation
  · Drawing + Rev update
  · BOM / requirements update
  · Notification to all departments (ECN)
5. Closure and Filing
  · Record in PLM/ERP
  · Baseline preserved
ECR — Engineering Change Request
The entry point to the process: who is requesting, what's the problem (field failure? cost reduction? supplier issue?), proposed solution, impact estimate. The CCB approves/rejects.
ECO — Engineering Change Order
The binding instruction: what changes + new Rev, Effectivity (S/N/date), disposition of existing inventory (Use-As-Is/Rework/Scrap).
ECN — Engineering Change Notice
The official distribution to everyone affected — manufacturing, purchasing, quality, suppliers. Ensures everyone is working from the same version.
🔎 Where-Used — Change Impact Analysis
Before any ECO — the first question: where else does this part live? A change to a "simple" bolt used in 40 assemblies = 40 required impact checks. A PLM answers this with one click; manual file-based tracking is a recipe for trouble.
🔤 REV System — Revision Management
VersionMethodUsage
A, B, C...Letters A-ZISO/ASME — very common
0, 1, 2...NumbersSome manufacturers
P1, P2...P=PreliminaryDevelopment stage, before approval
Rev -DashInitial drawing, pre-REV
Rev AFirst changeAfter initial Release
Don't skip letters! I, O, Q, S, X, Z are avoided (confusion with 1, 0, 0, 5, ×, 2). MIL-STD-100 explicitly prohibits them.

Redline — Red-Pen Correction
A temporary handwritten mark on a field drawing copy — until an official update. Only legal with an authorized signature + date + a follow-up ECO opened!
As-Built
The actual final condition — including approved deviations, material substitutions, and field repairs. Critical for project handover and failure investigations.
Interchangeability — FFF
Form-Fit-Function: a change that preserves FFF = same part number + new Rev. Breaking FFF = a new part number is mandatory!

💾 PLM — Product Lifecycle Management
The system that holds everything in one place: versioned CAD files, BOM, electronic ECO processes, digital signatures. The main benefit: a single source of truth — no "version sitting on someone's desk".
PDM — Product Data Management
The vault for CAD files: check-in/out (no overwrites!), automatic versioning, assembly-part relationships. SolidWorks PDM is common.
Full PLM
From idea to end-of-service: requirements, CAD, BOM, ECO, manufacturing, service. Windchill, Teamcenter, 3DEXPERIENCE.
📐 Configuration Management
Baseline — an approved configuration anchor point. Types: FBL (Functional — requirements), ABL (Allocated), PBL (Product — the full manufacturing documentation). Once fixed — every change goes only through an ECO.

Configuration Audit — compares: what's documented (Baseline) against what was actually built (As-Built). Mandatory before handing over a critical project.
Deviation — pre-approved deviation
"We know we won't meet requirement X — is that OK?" → engineering analysis → approval before production, for a defined batch/quantity.

Example: a hole diameter in raw stock deviates by 0.05mm — pre-approved because it doesn't affect assembly.
Waiver — after-the-fact approval
"An anomaly came out — what do we do?" → MRB reviews → approval after the part has already been produced non-conforming.

Example: a part already manufactured with a slightly rougher surface finish than required — MRB checks if it's still functionally acceptable.
⚠️ Golden Rules
• Both documents are limited in quantity/time — they do not change the official drawing!
• Full documentation is mandatory — not a "verbal decision"
• Repeated/permanent use of the same exception = a red flag — time to issue a real ECO and update the drawing
• A Deviation/Waiver living for months without a follow-up ECO = a ticking time bomb of conflicting versions
🔍 MRB — Material Review Board
The forum that decides the fate of nonconforming parts — those not meeting drawing requirements. Composition: engineering + quality (+ customer, on defense/critical programs).
DecisionMeaningRequires
Use-As-Is (UAI)Good as it is — despite the nonconformanceDocumented engineering justification!
ReworkAdditional processing to bring it within requirementsApproved process, re-inspection
RepairFix (not identical to original, but acceptable)A specially-approved repair process
ScrapComplete rejectionDocumentation + destruction/marking
⚠️ UAI (Use-As-Is) authority — for authorized personnel only! MRB Crib = a physical holding area for nonconforming parts awaiting a decision, preventing them from accidentally "rolling" into the production line.
🔒 ITAR / Export Control Requirements
▸ ITAR: International Traffic in Arms Regulations (USA)
▸ USML: US Munitions List — controlled items
▸ EAR: Export Administration Regulations (civilian + dual-use)
▸ ECCN: Export Control Classification Number

Drawing marking:
WARNING: This document contains technical data
subject to the Export Administration Regulations
(EAR). Export/transfer in violation of EAR
is prohibited. ECCN: 1C002

▸ Israel: defense export control — DECA (SIBAT)
▸ TP-10: export license request forms
CAGE Code
A 5-character code identifying a defense supplier worldwide. Appears on drawing title blocks, CoCs, purchase orders. Israel: DSPO. USA: DLIS.
Effectivity + ITAR
An ITAR drawing is an "export" even via email to a foreign national! Access is restricted to US Persons or requires a license. Violation = fines and imprisonment.
