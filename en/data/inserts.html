🌀 Helicoil / Wire Thread Insert — STI
What is a Helicoil?
Most CommonNASM 21209
PrincipleA coiled stainless steel wire inserted into an STI hole → a new thread
StrengthStronger than the original thread in Al! ×1.5-2 pull-out
Insert MaterialSS 304 · SS 316 · Phosphor Bronze · Inconel 600
SizesM3 to M39 · UNC 4-40 to 3/4"-10
Depth1D · 1.5D (common) · 2D · 2.5D · 3D
StandardsNASM 21209 · MIL-I-8846 · DIN 8140 · BS 4255
UsesThread repair · Al/Mg → ↑strength · engines · aerospace
Manufacturers: Helicoil (Stanley) · Böllhoff ENSAT · Recoil

🔐 Keensert / Key-Lock Insert — Solid Rigid
What is a Keensert?
Solid!NASM 33537
PrincipleA solid stainless steel insert with locking keys
Locking4 keys bite into the parent material → never rotates
Strength↑↑ Pull-out vs. Helicoil — recommended for heavy loads
MaterialSS 303 · SS 316 · Inconel 718
SizesM6 to M39 · #10-32 to 1"-8
StandardsNASM 33537 · MS122073 · DIN 8140 Type D
UseAerospace · defense · heavy loads · repeated-use Al
Manufacturers: Böllhoff (ENSAT) · KATO Locking · Keensert (Stanley)

⚙️ Press-fit / Self-Clinching Inserts — PEM
Self-Clinching Standoff / Nut
PEMThin metal sheets
PrinciplePress ← ← insert seats ← material flows around it
ResultA permanent joint ← high push-out force
Minimum Thickness0.5-1.5mm (depending on size and material)
Sheet MaterialsAl (Hard) · Steel · SS · Copper
⚠️ Soft AlSoft Al (1xxx) ← not suitable! PEM falls out
UsesPCB · signage · electrical cabinets · electronics
Manufacturer: PEM (Parker Hannifin)
▶ YouTube
Main PEM Types
S · SS · SO · SOFS
S (Nut)Press-in nut · M2 to M10 · steel
SS (Nut SS)Stainless · M2-M10
SO (Standoff)Spacer + thread · M2-M8 · adds height
SOFS (Floating)Thread floats ± 0.5mm · ← compensates for misalignment
K (Stud)Fixed stud · M2-M8
FH (Flush Head)Flush head · aerodynamic
Installing PEM
Press + Anvil
ToolA press (Hand/Pneumatic/C-Press) + a matching anvil
Installation Force0.3-35kN depending on size (from PEM chart)
⚠️ AnvilMandatory! Without an anvil = a bent sheet
TestingPush-out Force Test · Torque Test per PEM Spec
Never with a hammer! Press only
