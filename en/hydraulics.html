📐 Pascal's Principle and Basic Formulas
Core Formulas
// Pascal's Principle — pressure in a closed fluid is transmitted equally in every direction
F = P × A   // Force [N]. P=[Pa], A=[m²]
P = F / A   // Pressure [Pa=N/m²]
// Convenient pressure conversions
1 bar = 100,000 Pa = 10.2 kgf/cm² = 14.5 PSI
1 MPa = 10 bar = 145 PSI
// Flow rate and velocity
Q = A × v   // [m³/s] → ×60000 = [L/min]
v = Q / A   // Piston speed from flow rate
// Hydraulic power
P_kW = p[bar] × Q[L/min] / 600
// Piston areas (rod-side cylinder)
A_ext = π×D²/4   // Extend area (full)
A_ret = π(D²−d²)/4   // Retract area (minus rod)
▸ Retract area is always smaller than extend area → faster retract speed at the same flow rate, but lower force!
▸ Typical area ratio (Regeneration): 1.6:1 to 2:1

Reservoir — Oil Tank
Volume3-5× pump flow rate per minute [liters]
FunctionCooling, dirt settling, air release

Basic Circuit Diagram — Component Sequence
Reservoir → Suction filter → Pump → Relief valve (protection) → Directional control valve (DCV) → Cylinder/motor → Flow control valve (speed) → Return filter → Reservoir
▸ Relief always right after the pump — the circuit's first line of protection
▸ Return filter is no less critical than suction — it catches component wear debris

Meter-In vs Meter-Out
Meter-InRestricts incoming flow — positive (raising) load
Meter-OutRestricts outgoing flow — negative (lowering/falling) load
▸ Meter-Out prevents cavitation with an overrunning load — the safe choice for lifts and cranes
▶ YouTube
DCV — Center Position Coding
Closed CenterAll ports blocked — load locked
Open CenterP-T open — pump idles at zero pressure
Float CenterA,B to T — piston free to move
Tandem CenterP-T open, A,B closed — common in forklifts

💨 Pneumatics — Principles and Components
Comparison to Hydraulics
Operating Pressure4-8 bar (vs. 150-350 in hydraulics)
Efficiency~40% (hydraulics ~90%) — compressed air
ForceF=P×A — same formula, lower pressure
AdvantagesClean, safe (no fluid burst risk), fast, cheap
DisadvantagesLow force, noisy, imprecise (air compressibility)
FRL — Air Preparation Unit
FilterMoisture and dirt filter — 5-40 micron
RegulatorStabilizes a constant working pressure
LubricatorAdds an oil mist (older components only!)
▸ FRL always at the inlet of every pneumatic system — without it, fast failure follows
